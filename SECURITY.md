# Security reports

Use [GitHub private vulnerability reporting](https://github.com/sbenson2/PocketCPU/security/advisories/new) for potential security issues in PocketCPU. Reports sent through that form are private to the project maintainers and invited collaborators until publication.

Include the component and version, the connection route, what happened, and reproduction steps using a disposable sample project. Redact credentials, pairing codes, private code, and personal data. Do not test a host you do not own or have permission to test.

General setup questions and feature requests belong in public issues. PocketCPU is in development; a supported release policy will be recorded when a release is available.
